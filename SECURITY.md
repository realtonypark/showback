# Security

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/realtonypark/showback/security/advisories/new). Include affected code or version, impact, and minimal reproduction steps. Do not put credentials, private recordings, or sensitive app data in public issues.

The current development line is the focus for fixes. There is no support window or response-time guarantee during the developer preview.

Showback operates real applications. Review scripts before running them, use safe test accounts, and choose capture scope deliberately. Window capture is the default; display capture can contain unrelated visible information. Recordings remain local until you choose to share them.

Installers download pinned model/runtime assets and verify their identities. Source builds are ad hoc signed; signed/notarized binary releases are not currently provided. Downloaded components have their own licenses and upstream security considerations.
